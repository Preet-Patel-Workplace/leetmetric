# LeetMetric – LeetCode Analytics Dashboard

LeetMetric is a web-based analytics dashboard designed to visualize LeetCode user performance in a clear and structured manner. The application retrieves real-time user statistics from the LeetCode platform using its GraphQL API and presents them through an intuitive, LeetCode-inspired interface.

This project demonstrates practical frontend development skills, API integration, data visualization, and user-focused interface design.

---

## Project Overview

LeetMetric allows users to enter a LeetCode username and instantly view problem-solving statistics categorized by difficulty level (Easy, Medium, and Hard). The dashboard includes animated progress indicators, summary statistics, and a profile section to provide a comprehensive snapshot of a user’s coding progress.

The application is built entirely with client-side technologies and focuses on clean architecture, responsiveness, and usability.

---

## Features

- Real-time retrieval of LeetCode user statistics using GraphQL  
- Visualization of solved problems by difficulty level  
- Animated circular progress indicators  
- Profile header displaying the queried username  
- Summary metrics including total problems solved and acceptance rate  
- Skeleton loading state for improved user experience  
- Input validation and structured error handling  
- Responsive design for desktop and mobile devices  
- Dark theme inspired by LeetCode’s official interface  

---

## Technology Stack

- HTML5 – Semantic markup and layout structure  
- CSS3 – Responsive styling, animations, and theming  
- JavaScript (ES6+) – Application logic and DOM manipulation  
- GraphQL – Data querying language  
- LeetCode Public API – Source of user statistics
