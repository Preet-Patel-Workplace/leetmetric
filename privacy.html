Privacy Policy

Last Updated: April 14, 2026

This Privacy Policy explains how LeetMetric (a personal portfolio project) handles data. This project is hosted on GitHub Pages and is intended for educational and demonstration purposes only.

1. Data Collection

LeetMetric does not collect, store, or share any personal identifiable information (PII). We do not require account registration, and we do not ask for passwords, email addresses, or financial information.

2. Use of Public Data

Our tool only processes public LeetCode usernames provided by the user. This data is used solely to fetch public statistics (such as problem-solving counts and rankings) via public APIs. This data is processed in the browser and is not saved to any database.

3. Cookies and Tracking

This website does not use tracking cookies, advertising pixels, or third-party analytics that track your behavior across the web.

4. Third-Party Hosting

This site is hosted by GitHub Pages. As such, GitHub may collect some log data as part of their standard hosting operations. Please refer to the GitHub Privacy Statement for more details.

5. Contact

If you have any questions about this project, you can contact the developer through the GitHub repository profile.
